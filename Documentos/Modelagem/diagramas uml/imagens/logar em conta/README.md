#### Descrição

**Tela inicial (login):**

Tela inicial do sistema na qual o usuário irá ler informações sobre o objetivo do site e também poderá logar em uma conta já criada.

caso o usuário deseje ler sobre o scrum na integra existirá um link direcionado diretamente para o site oficial scrum.

logar em sua conta já criada exige: 
- CPF 
- Senha

dessa forma ele poderá acessar o site, tendo acesso a dashboard do site.

Em caso do usuário não possuir uma conta já criada ele pode clicar em criar uma conta, levando para uma tela de criação de conta, assim criando uma conta no banco de usuários

Pré-condiçâo: 
- assim que o usúario entrar no site essa será a tela principal e primeira a ser revelada
- ao tentar logar em uma conta a conta ja deve estar salva no banco de dados.
- em caso de esquecimento de senha o usuário deve definir seu cpf para mudar a senha atual por uma outra senha

**Usuário:**

Representa um usuário cadastrado na plataforma, responsável por acessar os níveis disponíveis, realizar tentativas  acompanhar seu desempenho no sistema e gerar seu certificado.
