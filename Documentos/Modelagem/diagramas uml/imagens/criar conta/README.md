#### Descrição

**Tela de criação do usuário:**

Descrição: nesta tela o usuário irá visualizar os campos que precisam ser prenchidos para concluir a criação da conta.

exibindo os campos:
- nome 
- sobrenome
- CPF
- E-mail
- Senha
- Confirmar seha
   Após isso ele clicará em confirmar para realizar a criação da conta. 
info: necessario informar que todos os campos são obrigatórios.

Em caso do usuário clicar errado ou decidir não criar a conta a tela deve possuir um botão para retornar a tela inicial.


**Pré-condição:** 
- usúario deve preencher todos os campos e o CPF e o E-mail n podem ja estar cadastrados em outra conta.

**Usuário:**

Representa um usuário cadastrado na plataforma, responsável por acessar os níveis disponíveis, realizar tentativas  acompanhar seu desempenho no sistema e gerar seu certificado.
