# 🎨 Design da Aplicação

Esta pasta reúne toda a documentação relacionada ao design da aplicação, incluindo decisões visuais, identidade gráfica, componentes de interface e diretrizes de experiência do usuário.

O design da aplicação foi definido durante a [Sprint 1](../../README.md#sprint1) pelos membros:

- [Paulo Olivetti](https://github.com/pauloolivetti)

## 🎯 Objetivos do Design

O sistema visual da aplicação foi desenvolvido com foco em:

- Consistência visual
- Legibilidade
- Acessibilidade
- Escalabilidade
- Experiência intuitiva para o usuário
